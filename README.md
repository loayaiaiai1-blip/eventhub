# EventHub 🎉

**EventHub** is a Flutter application designed to help users manage and organize their events بسهولة. It provides a simple and user-friendly interface to make event management easier.

## 📱 About the Project

EventHub aims to provide users with a convenient platform to manage their events, organize their plans, and keep everything in one place.

## ✨ Features

- User-friendly and modern UI.
- User authentication screens.
- Sign in and Sign up interfaces.
- Google and Facebook social login UI.
- Reusable custom widgets.
- Organized and maintainable code structure.

## 🛠️ Technologies Used

- **Flutter** – UI development framework.
- **Dart** – Programming language.
- **Flutter Bloc** – State management.
- **GoRouter** – Navigation and routing.
- **Flutter SVG** – SVG image rendering.
- **Google Fonts (Poppins)** – Typography.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- An Android emulator or physical device

### Installation

1. Clone the repository:

```bash
git clone https://github.com/loayaiaiai1-blip/eventhub.git
```

2. Navigate to the project directory:

```bash
cd eventhub
```

3. Install dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```
